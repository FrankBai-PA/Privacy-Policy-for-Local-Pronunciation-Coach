Privacy Policy for Local Pronunciation Coach

Local Pronunciation Coach helps users save English words, hear pronunciations, view phonetic spelling and definitions, and export daily vocabulary CSV files.

Data stored locally:
The extension stores saved words, settings, practice counts, phonetic spelling, and definitions in Chrome local storage on the user's device.

Data sent externally:
When the user clicks the dictionary button for a word, that single clicked word is sent to the public Free Dictionary API at api.dictionaryapi.dev to retrieve phonetic spelling and a concise definition. The extension does not automatically send browsing history, full page content, or any words unless the user requests a definition.

Data not collected:
The extension does not collect names, email addresses, passwords, financial information, health information, location, browsing history, or personal communications.

Data sharing:
The extension does not sell user data. It does not use user data for advertising, analytics, creditworthiness, or lending purposes.

CSV export:
CSV files are generated locally and saved by the user through Chrome downloads.
